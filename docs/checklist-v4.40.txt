bento_enhanced v4.40: Analog as an oscillator Type, mixed sync, Shape modulation, OSC identity (stock 1.6.8)
=========================================================================================================

Kit: flash\bento_enhanced-v4.40   boot label BE4.40
  01_TEST_FIRMWARE   bento1.bin = the test image on 1.6.8, bento2.bin = stock 1.6.8 Controller
  03_RESTORE_STOCK   stock 1.6.8 (bento1.bin, bento2.bin)
  SHA256SUMS.txt     hashes of every file in the kit
  manifest.json      what the image contains (groups, addresses, every write)
  DEVICE_CHECKLIST.txt  this file (docs\checklist-v4.40.txt)

Plans: docs\plan-native-props.md (P1: Analog is a native property of each Wavetable oscillator) and
docs\plan-be440-sync-identity.md (mixed sync, Shape modulation, the OSC1 / OSC2 identity). Everything below was
measured in the emulator only. Nothing in this kit has run on a device.

In this image (new since BE4.22, the last kit run on the device):
  - The instrument menu is stock's again: 8 entries, no "Analog". An Analog sound is a Wavetable track whose
    oscillator has Type = Analog. Each oscillator has its own Type, so OSC1 Analog with OSC2 Wavetable is normal.
  - Rows on the Wavetable page (slot 1 = the first knob of a row):
      OSC1 Wavetable : Level, Pitch, Position, Type
      OSC1 Analog    : Level, Pitch, Shape, Type, Glide
      OSC2 Wavetable : Level, Pitch, Position, Type
      OSC2 Analog    : Level, Pitch, Shape, Type, Sync 1>2
    Row 3's WTOscReset is hidden while BOTH oscillators are Analog.
  - Sync 1>2 (on OSC2 whenever OSC2 is Analog): OSC2 restarts on every cycle of OSC1. It now works with OSC1 Wavetable
    (mixed sync, even with no WAV on OSC1) as well as with OSC1 Analog. On BE4.22 both-Analog sync never engaged on the
    device (bug B1: the device renders 256-frame blocks), and this kit fixes that.
  - Shape (0..127): 0..48 saw, 48..88 saw morphs to square, 88..127 the square narrows to an 8% pulse. Its value
    reads "Saw", "Saw>Sq 40%", "Square", "Pulse 30%". Sine and triangle are not in this kit.
  - Shape modulation: on an Analog oscillator, whatever is routed to "OSC1: Position" (or "OSC2: Position") moves
    Shape instead. An LFO there gives PWM.
  - Names: the panes read "OSC1: ..." / "OSC2: ..." on every Wavetable track (they were "WT1: " / "WT2: "). The mod
    destinations read "OSC1: Position", "OSC2: Level" and so on, to match.
  - An Analog oscillator's pane shows a Shape dial (saw / square / pulse glyphs, the nearest one lit) instead of a
    wavetable. Its title reads "OSC1: Analog". On the first Analog oscillator it adds "DSP nn%" (the audio core's
    total load, refreshed while you play) and "OVER" after a block went over budget. A WAV still loaded on an
    Analog oscillator shows as "(WAV kept)" or "+WAV".
  - A double-tap on an Analog pane no longer opens the WAV browser.
  - Saved in the project as bento_osc_type / bento_shape / bento_sync / bento_glide on each oscillator. Stock 1.6.8
    ignores them and plays plain Wavetable.
NOT in it: the drum synth (BE4.50+; this image leaves drums out), Sub FM, Bit Depth, FM 1>2 (P3), sine / triangle,
the reverse sync (Analog OSC1 master, Wavetable OSC2: hidden), migration of BE4.22 .. BE4.31 Analog projects (decision
NP3: none: they open as plain Wavetable tracks).

Offline measured cost: a synced Analog OSC2 adds about 2.3k instructions per voice-block at note 60, and up to about
7.2k at the top of the range. The worst case is 80 synced voices at about 570k of the 1.28M-cycle block (inferred):
section 7 checks it.
