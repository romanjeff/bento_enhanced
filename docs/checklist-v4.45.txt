What changed since BE4.44:
  - A Wavetable track's Mod Matrix has three more rows: OSC1: Sub FM (after OSC1: Position), OSC2: FM 1>2 and
    OSC2: Sub FM (after OSC2: Position). 26 rows. The oscillator rows now read "OSC1: ..." / "OSC2: ..." (BE4.44 showed
    "WT1: ..." / "WT2: ..."). The CC column of the new rows is blank.
  - A routing moves the knob: amount 100 % with the source at full moves the knob by the whole travel (0..100 %), then
    the usual depth curve. The knob is where the travel starts; the result is held to 0..100 %.
  - OSC2: Sub FM has no knob (since BE4.43). It plays only while routed, starting from 0, next to FM 1>2.
  - The depth follows the source once per block (2.7 ms), ramped across the block (no zipper).
  - Works on Analog and Wavetable oscillators; with the knob at 0 a routing alone turns FM on.
  - The piano roll's destination list is unchanged (stock's): no lanes on these.
What to expect that is not a bug:
  - The modulation is block rate: an LFO above about 100 Hz on an FM amount aliases (folds above 187 Hz). Use the FM
    rows' own audio-rate sources (Sub FM, FM 1>2) for audio-rate effects.
  - seq1..seq4 routed to the same FM row share one slot (stock's rule for every destination): the last one wins.
  - A Wavetable OSC2's Sub FM starts from 0 even if an old project stored a value for it (an Analog OSC2 starts from it).
