What changed since BE4.42 (your design, 2026-11-16):
  - One FM amount per oscillator, then its FM envelope. The Analog rows (knobs 1..8):
        OSC1:  Level, Pitch, Shape, Type, Glide,    Sub FM, FM Atk, FM Dec
        OSC2:  Level, Pitch, Shape, Type, Sync 1>2, FM 1>2, FM Atk, FM Dec
    When OSC1 is NOT Analog (Wavetable), OSC2's knob 6 shows Sub FM instead of FM 1>2 (so OSC2 always has an FM
    source; Claude's default, told to you). Each oscillator keeps its own FM Atk / FM Dec.
  - OSC2's Sub FM no longer plays while OSC1 is Analog (its stored value is kept, and plays again if OSC1 goes back
    to Wavetable). A BE4.42 project with Sub FM set on OSC2 next to an Analog OSC1 therefore sounds different: that
    Sub FM is gone (expected change).
  - The FM envelope: the amount's depth x env. env rises 0 -> 1 over FM Atk (straight in depth, an even swell), then
    falls exponentially over FM Dec (the time Dec names is the time to -60 dB, then it is 0). FM Dec at its top is
    "Inf": hold 1 = BE4.42's static depth. FM Atk 0 = instant. Both default to 0 / Inf, so BE4.42 projects sound as
    before (but for the OSC2 Sub FM case above). The envelope restarts at every note start, per voice.
  - Times on the knob (one detent = one value, 128 values on Atk, 129 on Dec):
        value   0       1       20     32      48      64      80      96      112     127
        time    0 ms*   5.3 ms  83 ms  173 ms  384 ms  776 ms  1.52 s  2.90 s  5.51 s  10.0 s
        (* FM Atk 0 is instant; FM Dec 0 is the shortest fall, one block = 2.7 ms; FM Dec above 127 is Inf)
    The curve is exponential at the top (about 4 % a step) and one block (2.7 ms) a step at the bottom.
What to expect that is not a bug:
  - The envelope moves once per audio block (2.7 ms) and the depth ramps smoothly between blocks, so there is no
    zipper, but nothing is faster than 2.7 ms. FM Dec 0 gives a 2.7 ms "tick" of brightness.
  - A retrigger restarts the envelope at 0 (or at 1 with FM Atk 0) whatever it was doing: on a fast repeated note with
    a long attack each note starts dull again (a hard retrigger, as designed). Legato notes (Glide) most likely
    retrigger too (they go through the same note start; not measured on the device).
  - A note whose envelope has decayed to 0 still costs the FM's CPU (the FM runs at depth 0).
