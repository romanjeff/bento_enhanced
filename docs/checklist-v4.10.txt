bento_enhanced v4.10: v3.72 parity on stock 1.6.8 (sprints S4+S5, milestone M2), minus the deferred Mod Matrix
================================================================================================================

Kit: flash\bento_enhanced-v4.10   boot label BE4.10
  01_TEST_FIRMWARE   bento1.bin = the test image on 1.6.8, bento2.bin = stock 1.6.8 Controller
  03_RESTORE_STOCK   stock 1.6.8 (bento1.bin, bento2.bin)
  SHA256SUMS.txt     hashes of every file in the kit
  manifest.json      what the image contains (groups, addresses, every write)

In this image (everything v3.72 has, except what Jeff deferred):
  - black box (logs, RAMCHK, M4 alarms, crash record); stall / watchdog hooks NOT patched in (as v3.72)
  - poly cap (External, 6 voices), retriggers, curve playback (External and internal), trigger conditions,
    Note Mod (internal melodic, drum, External via the SEQ page button)
  - step inspection (150 ms hold), per-step Condition / Retrig / Division / Ramp encoders (drum 5-8, piano
    roll 7), pad defaults and locks, strike velocity ("Strike Vel" button), the probability clamps
  - be_step_v1 save / load and curves.bnt (the per-step data and curves survive a save on BE4.10)
  - hold shortcuts (TRACKS / LAUNCH / MIXER / INST + pads)
  - live poly AT and AT Out (External 0xA0 / 0xD0, internal instruments), AT Rec
NOT in it (deferred, Jeff): the Mod Matrix page and the External INST rows (Main / LFO 1-2 / Env 1-2 / Note Mod
  buttons on the External INST page). Without them the External modulation engine is off: routings a v3.72
  project has (LFO / envelope -> CC, pitch bend, AT) do NOT play on BE4.10, but they are kept in curves.bnt
  and come back on v3.72. Note Mod on External tracks works through the SEQ page button as on v3.72.
Dropped (in the official firmware): PLAY+pad mute.

5. What to look for in the logs
  - Header: "firmware BE4.10"; "!!!" lines (alarms), "M4 main-task stall", "M7 audio stall record": any of these, bring
    the log. "wd worst gap" under its limits.
  - RAMCHK: axi / top changed=0 from the second boot on.
  - "# saved:" line: poly stolen / retrig / swallowed (section 4), curves started / sent / late / skipped (skipped > 0:
    more than 64 curve notes at once).
  - "SAVE <path> | sidecar status=.. curves=.. bytes=..": the path must be the project just saved (SPACED_410), curves
    = the number of curves; "pool used" and "ext heap free" not near 0.
  - "INSERTS total=.. by caller: <address>xN ... | recw n=.. nonzero=0": nonzero must stay 0 (section 4).
  - "PARAM edits=..", "TOGGLE presses=..", "STRIKE-LATE queued=.. applied=..": strike / defaults activity; "HDR pages:"
    the header pages seen and where our buttons sat ("nm_slot", "out=", "applied=").
  - "MX mx_ctx=0 ...": always 0 on BE4.10 (the Mod Matrix is not in it).

6. Bisect (if something is wrong): ask for a build with one group off and compare
  Each of these builds on 1.6.8 (boot label set with BE_LABEL, e.g. "BEnoS"):
    BE_DISABLE=step       step UI, strike velocity, be_step_v1 save / load, curves, Note Mod UI (and the M4 side of
                          everything that needs per-step data): first suspect for a crash on the step page or at save
    BE_DISABLE=hold       hold shortcuts
    BE_DISABLE=poly_at    live poly AT (External handler, M4 MIDI 0x5F / 0x60)    BE_DISABLE=poly_cap  the 6-voice cap
    BE_DISABLE=inta_live  live AT on internal instruments                          BE_DISABLE=inta_curve curves on internal
    BE_DISABLE=retrig     retriggers + curve playback hooks                        BE_DISABLE=nmod      Note Mod engine
    BE_DISABLE=cond_engine conditions (M7)    BE_DISABLE=cond_ui  probability clamps    BE_DISABLE=trace / bbox  black box parts
    BE_DISABLE=rmidi      MIDI retrigger hits on External tracks (internal hits stay)
    Old names still work: poly, cond, inta (both halves), diag, diag7. Everything off: build_m1_off.sh's default list.
    A misspelt name is refused by the build (it used to build the default image silently): a bisect kit's
    manifest.json lists the groups it left out ("disabled"); check it before flashing.
  A disabled group's stock sites stay unpatched (its code stays in the image, unreachable).
