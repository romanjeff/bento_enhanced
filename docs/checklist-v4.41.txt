bento_enhanced v4.41: Sub FM, FM 1>2, Bit Depth, sine / triangle, glide time fix (stock 1.6.8)
==============================================================================================

Kit: flash\bento_enhanced-v4.41   boot label BE4.41
  01_TEST_FIRMWARE   bento1.bin = the test image on 1.6.8, bento2.bin = stock 1.6.8 Controller
  03_RESTORE_STOCK   stock 1.6.8 (bento1.bin, bento2.bin)
  SHA256SUMS.txt     hashes of every file in the kit
  manifest.json      what the image contains (groups, addresses, every write)
  DEVICE_CHECKLIST.txt  this file (docs\checklist-v4.41.txt)

Plan: docs\plan-p3-fm-bits.md (P3; section 8 is the source of this list, "Release notes (BE4.41)" the changes in
words). Everything below was measured in the emulator only. Nothing in this kit has run on a device, and BE4.40 has not
either.

In this image (new since BE4.40):
  - Rows on the Wavetable page, Analog oscillators (slot 1 = the first knob of a row):
      OSC1 Analog : Level, Pitch, Shape, Type, Glide,    Sub FM, Bit Depth
      OSC2 Analog : Level, Pitch, Shape, Type, Sync 1>2, Sub FM, Bit Depth, FM 1>2 (only while OSC1 is Analog)
    Wavetable rows are unchanged.
  - Sub FM (0.0 .. 100.0 %): the track's sub oscillator frequency-modulates this oscillator, through zero. The knob is
    squared (50 % = a quarter of the depth). The sub's Level does not matter: the sub modulates at Level 0 too. A
    Square sub at any Pulse Width keeps the pitch centre (its DC is removed).
  - FM 1>2 (0.0 .. 100.0 %, OSC2 only): OSC1 frequency-modulates OSC2. OSC1 must be Analog (hidden otherwise). It works
    with OSC1's Level at 0. OSC1's own Sub FM and its Bit Depth are in the modulator.
  - Bit Depth (Full / 12 / 8 / 4) per oscillator, not on the sub. The audio is crushed before Level.
  - Shape below the saw: 0..2 sine, 3..21 sine > triangle, 22..26 triangle, 27..44 triangle > saw, 45..48 saw; 48..127
    as BE4.40. Texts: "Sine", "Sin>Tri n%", "Tri", "Tri>Saw n%", "Saw", then BE4.40's. The dial has five glyphs: sine,
    triangle, saw, square, pulse.
  - Glide now takes the time it is set to (50.0 % = 1 s). BE4.40 and earlier glided twice as fast on the device.
  - Saved as bento_subfm / bento_bits / bento_fm12 on each oscillator (next to BE4.40's four).
  - Black box: the ANALOG line gains fm= (renders with FM), bits= (crushed renders), fmx=<skipped>/<missed>.
Behaviour changes (expected, no migration): a BE4.40 project with Shape < 45 now plays sine or triangle (BE4.40 played
saw there); every Glide is twice as long as on BE4.40; going back to BE4.40 drops the three new values on its next save.
NOT in it: the drum synth (BE4.50+), FM 1>2 from a Wavetable OSC1, OSC2 -> OSC1, FM amounts as Mod Matrix destinations.

Two FM tuning quirks, kept on purpose (Jeff, OD17 / OD18 = keep; docs\plan-p3-fm-bits.md):
  - OD17: OSC1's own Sub FM gives OSC1's signal a DC, and FM 1>2 turns that into a pitch shift of OSC2 (up to about an
    octave at FM 1>2 100 %, moving with OSC1's Sub FM and Shape). Expected: FM's own character, not a fault.
  - OD18: at 4 bits some Shapes give OSC2 a small pitch shift under FM 1>2 (about +17 cents at Shape 36, note 60).

Offline measured cost (instructions per voice-block of 256 frames, note 60, both oscillators saws, a sine sub; the
block budget is 1.28M cycles; flash wait states make device cycles higher than instructions):
  FM off 13.3k (BE4.40 13.2k)   Sub FM on both 27.3k   FM 1>2 alone 19.0k   full FM (Sub FM both + FM 1>2) 30.8k
  full FM synced 32.9k   full FM with OSC1 at 8 bits 35.3k   full FM with triangle carriers (Shape 24) 37.5k (the
  heaviest measured voice: 1.21 x the full-FM gate; Sub FM alone on triangles 33.4k = 1.12 x its gate)
  Shape 0 / 24 FM off at note 60: 13.1k / 11.8k (a saw or less); a blend (Shape 12, 36) ~23.5k = 1.77 x the saw; the
  plateaus rise with pitch (sine ~1.3 x the saw at note 96, ~2 x near note 119).
Section 8 checks these on the device.
