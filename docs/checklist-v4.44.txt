bento_enhanced v4.44: FM on Wavetable oscillators (stock 1.6.8) - delta checklist on top of v4.43
==================================================================================================

Kits (three, the same firmware but for one constant, D5: how soon heavy FM goes to a duller, cleaner copy of the table):
  flash\bento_enhanced-v4.44          boot label BE4.44   the release (mip threshold 1.75)
  flash\bento_enhanced-v4.44-mip1.5   boot label BEM1.5   a step cleaner (and duller) under heavy FM
  flash\bento_enhanced-v4.44-mipoff   boot label BEMOFF   "never go darker": the note's own level under any FM
  Each kit:
  01_TEST_FIRMWARE   bento1.bin = the test image on 1.6.8, bento2.bin = stock 1.6.8 Controller
  03_RESTORE_STOCK   stock 1.6.8 (bento1.bin, bento2.bin)
  SHA256SUMS.txt     hashes of every file in the kit
  manifest.json      what the image contains (groups, addresses, every write; "wt_mip" = its threshold)
  DEVICE_CHECKLIST.txt  this file (docs\checklist-v4.44.txt)

Plan: docs\plan-wt-fm.md (sections 2, 3, 9 and "W4 result"). Release notes: docs\release-notes-v4.44.md. Everything below
was measured in the emulator only. This is a delta on BE4.43: docs\checklist-v4.43.txt still applies, except its section 2's
last item and section 4's "Mixed mode" item (OSC2's knob 6 next to a Wavetable OSC1 is FM 1>2 now, see "What changed").
Run the release kit (BE4.44) for everything; the two alternates only for section 7.

What changed since BE4.43:
  - A Wavetable oscillator has FM, at the Analog knob numbers (slot 5 stays empty):
        OSC1 Wavetable:  Level, Pitch, Position, Type, -, Sub FM, FM Atk, FM Dec
        OSC2 Wavetable:  Level, Pitch, Position, Type, -, FM 1>2, FM Atk, FM Dec
    Same depth law, envelope and times as Analog (checklist-v4.43's table holds for FM Atk / FM Dec).
  - FM 1>2 works from either OSC1 type into either OSC2 type. The modulator is OSC1 before its Level (OSC1 at Level 0
    still modulates: "mute the modulator, hear the FM").
  - OSC2's knob 6 is FM 1>2 whatever OSC1 is. BE4.43 showed an Analog OSC2's Sub FM there next to a Wavetable OSC1: that
    Sub FM no longer plays (value kept), and a hidden FM 1>2 value that OSC2 held now plays (expected change, D2).
  - Mixed sync (Wavetable OSC1 master, Analog OSC2 slave): OSC1's Sub FM plays as 0 while synced (value kept, D3); FM 1>2
    keeps working, the slave following OSC1 block by block (2.7 ms).
  - A table frame's DC (average) is taken out of FM 1>2's modulator, so pulse / half-wave frames do not detune OSC2.
  - The hold-shortcut code moved to a new flash page (to make room for this release): they must still work (section 1).
What to expect that is not a bug:
  - Under heavy FM a Wavetable oscillator reads a duller, cleaner copy of its table (one mip level coarser), crossfaded in
    one block. On the release kit nothing changes up to about a third of the knob (amount 330 at any note); at full
    depth at note 60 it is one level duller than the note's own and aliases about 8 dB more than stock's rule would.
  - High notes under heavy FM alias (the coarsest level is reached): as stock above about 4.5 kHz.
  - A note that starts with FM already on plays its FM level from the first block (no crossfade at a note start, as
    stock's own level switch there). An FM Atk that sweeps the depth across a level boundary crossfades there.

    - hold TRACKS: top-row pads open tracks 1..8's instrument page, bottom-row pads their sequencer; release stays there;
    - hold LAUNCH: bottom row starts a track's selected clip, top row stops it; release goes back; a plain tap stays;

    - hold INST in a drum sequencer: a pad picks the sound, release returns to the sequencer with it selected;
    - while a hold button is down pads play no notes; PROJ + pad plays as stock.
    If any of these fails: stop, bring BENTO_DIAG.log (the fallback layout, 1b, is ready to build).
