Kit: flash\bento_enhanced-v4.46, boot label BE4.46.
  01_TEST_FIRMWARE   bento1.bin = the test image on 1.6.8, bento2.bin = stock 1.6.8 Controller

Plan: docs\feasibility-fm-env-sources.md (its decisions and the "S1 / S2 as built" sections). Release notes:
docs\release-notes-v4.46.md. Everything below was measured in the emulator only. This is a delta on BE4.44:
docs\checklist-v4.44.txt still applies (its D5 pick, section 7, is not needed again unless you want to change it).
The two BE4.44 alternate kits (mip 1.5, mip off) are not rebuilt for BE4.46: this release has the release threshold (1.75).

What changed since BE4.44:
  - A Wavetable track's Mod Matrix page has two more sources, right after Envelope 2:
        [None], Velocity, Pressure, Envelope 1, Envelope 2, FM Env 1, FM Env 2, LFO 1, LFO 2, Mod Seq, Key, Mod Wheel,
        Macro X, Macro Y, Auto A, Auto B, Auto C, Auto D
    FM Env 1 is OSC1's FM envelope (its FM Atk / FM Dec), FM Env 2 is OSC2's: on an Analog and on a Wavetable oscillator.
  - They are per voice and restart at every note, like Envelope 1 / 2. They run whenever the oscillator's FM Atk / FM Dec
    is set, even at FM amount 0, so you can use the FM envelope as a third / fourth envelope without any FM.
  - An oscillator whose envelope is unset (FM Atk 0 and FM Dec Inf) gives a constant full value (1, as its FM depth does):
    a routing from it is a fixed offset.
  - Nothing else changes. No other track type lists them (Granular's list is stock's).
What to expect that is not a bug:
  - The value moves once per audio block (2.7 ms), as stock's own envelopes do.
  - Routed to an Envelope or LFO parameter (Env 1 / 2 times, LFO rate / depth), FM Env acts one block late, the same lag
    stock already has between its own sources there.
  - In the file the routing is stock's: src="env3" (FM Env 1) or src="lfo3" (FM Env 2). Section 6 says what older firmware
    does with it.
